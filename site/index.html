支持 macOS 和 Windows。为应用选好主题、保存绑定后，
可以从 Openlude 启动，也可以留在后台，沿用原来的应用入口。

使用方法

  1. 1. 添加应用

    选择本机的 .app，或 Windows 的 .exe / .lnk。首次打开时列表为空，由你自己添加。

  2. 2. 选主题，保存绑定

    选择主题，按需调整时长、图标开场、原声或柔和模式，点击「保存绑定」。

  3. 3. 打开应用

    点击「启动应用」。也可以让 Openlude 保持后台运行，再从 Dock、桌面或开始菜单打开。

每个应用单独保存设置。支持系统深浅主题、登录启动和菜单栏 / 系统托盘；设置入口在工作台左下角。

常见问题

从原来的入口打开，为什么没有动画？+

请确认 Openlude 仍在运行，并开启「设置 → 通用 → 从系统入口启动时播放动画」（默认开启）。检测只对新启动的已绑定应用生效，已经运行的应用切回前台时不会重复播放。

动画什么时候出现，能跳过吗？+

从 Openlude 启动时先显示动画；系统入口检测发生在应用启动之后，启动很快的软件可能先出现自己的窗口。动画末段会渐隐，露出后方应用。全屏播放时可以按 Esc 跳过。

这个版本可以自动更新吗？+

1.0.0 会自动检查新的正式版本，并提供「下载安装包」入口。退出 Openlude 后安装新版，本机配置会保留。Mac 的应用内自动替换安装需要开发者签名，当前采用普通安装包更新。
